# pai-radical-accessibility — Project Context

## Purpose

A toolkit for converting architectural images into tactile formats for PIAF (Picture In A Flash) machines, making visual content accessible to blind and low-vision users. Designed for architecture students who need to access visual course materials and create tactile versions of design work.

**Core design principle**: Accessibility first — every aspect is designed for screen-reader compatibility and non-visual operation. No visual inspection should be required.

## Technical Stack

- **Python 3.10+** (tested on 3.12)
- **CLI Framework**: Click (screen-reader friendly)
- **Image Processing**: Pillow, NumPy, OpenCV
- **OCR**: EasyOCR (primary), Tesseract (fallback)
- **Braille**: Liblouis (Grade 1 and 2)
- **PDF Generation**: ReportLab (300 DPI)
- **Configuration**: PyYAML
- **MCP**: FastMCP for Claude integration

## The Two CLIs

| CLI | Package | Purpose |
|-----|---------|---------|
| `tact` | `tactile-core` | Convert images to PIAF tactile PDFs |
| `tasc` | `tasc-core` | Programmatic Rhino design with accessible feedback |

Install: `pip install -e lib/tactile-core/` and `pip install -e lib/tasc-core/`

## Processing Pipeline

1. **Load** — Validate and open image (JPG, PNG, TIFF, BMP, GIF, PDF)
2. **Convert** — RGB to grayscale
3. **Enhance** — Optional contrast enhancement (S-curve, CLAHE, auto-contrast)
4. **Threshold** — Binary B&W conversion (configurable, preset-driven)
5. **Density check** — Ensure <40% black pixels (prevents PIAF paper swelling)
6. **Text detection** — EasyOCR finds labels and dimensions
7. **Braille conversion** — Liblouis translates to Grade 1/2 Braille
8. **Auto-scaling** — Enlarge image so Braille fits in original text boxes
9. **Abbreviation key** — Generate key page for labels that don't fit
10. **PDF generation** — 300 DPI output with optional tiling for oversized images

## Accessibility Design Principles

- No emojis or visual-only symbols in CLI output
- Clear status messages: `Loading:`, `Processing:`, `Success:`, `Error:`
- Progressive disclosure (basic, verbose, interactive modes)
- Real-time output with no buffering
- Every error includes a suggested solution
- Braille labels on all generated text (dual-render: Braille + print)

## MCP Server

The tactile MCP server exposes tools to Claude: `image_to_piaf`, `list_presets`, `analyze_image`, `describe_image`, `extract_text_with_vision`, `assess_tactile_quality`. Configure via `.mcp.json` (see `.mcp.json.example`).

## Coding Conventions

- Screen-reader friendly logging via `AccessibleLogger`
- Custom exceptions with descriptive messages
- All inputs validated before processing
- YAML-based configuration (`tactile_standards.yaml`, `presets.yaml`)
- Separation of concerns: CLI, processing, generation, config in separate modules
- 10 optimized presets: floor_plan, section, elevation, site_plan, sketch, diagram, technical_drawing, photograph, presentation, detail_drawing

## Common Tasks

```bash
# Convert an image
tact convert floor-plan.jpg --preset floor_plan --verbose

# With Braille labels
tact convert plan.jpg --detect-text --braille-grade 2

# Batch convert
tact batch ./drawings ./output --preset floor_plan --verbose

# List presets
tact presets

# TASC site layout
tasc site 200 150 && tasc zone living 50 40 --at 10,10 && tasc describe
```
